Components of HAGLE:

- H - Hash Algorithm: Identifies the algorithm (e.g., MD5, SHA1, SHA256) used for data integrity.
- A - Authentication Method: Determines how peers prove identity, such as Pre-Shared Keys (PSK) or RSA digital certificates.
- G - Group (Diffie-Hellman): Specifies the Diffie-Hellman group (e.g., Group 2, 5, 14) used to generate shared secret keys for encryption.
- L - Lifetime: Determines how long the IKE Phase 1 SA (Security Association) is valid before being renegotiated, often in seconds or kilobytes.
- E - Encryption Algorithm: Defines the method used to encrypt data, such as DES, 3DES, or AES.

Interesting notes (**some are generated by IA**):

  - There's a difference between FSM (Finite State Machine) and Anti-replay (really a window, not a queue) queuesÖ

    - FSM belongs to IKE (key/session negotiation), not to the actual encrypted traffic. IKEv2 negotiation is typically implemented as a state machine (e.g., states like INIT → AUTH → ESTABLISHED → REKEYING → DELETING).  Because many things can trigger a state transition — incoming IKE messages, retransmission timers, rekey timers, admin commands (delete SA, bring up tunnel), DPD events — implementations serialize these triggers through a queue so the FSM processes one event at a time per SA/session. This avoids race conditions where, say, a rekey event and an incoming DELETE message try to mutate the same SA state concurrently.

    - Anti-replay belongs belongs to the data plane — ESP/AH packet processing per RFC 4303. Each packet carries a sequence number, and the receiver tracks a sliding window (usually a bitmap) of which sequence numbers within the current window have already been seen. When a packet arrives:

      - If its sequence number is too old (outside the low end of the window), it's dropped as a replay.
      - If it's within the window but the bit is already set, it's dropped as a duplicate.
      - If it's new, it's accepted and the bitmap is updated.

  - In C, there's functionally no difference between `ikeStruct *ike` and `ikeStruct* ike`, * binds to the variable name.
    The difference is purely style/convention, and it matters mainly when you declare multiple variables on one line:

    ```sh
    ikeStruct* a, b;   // gotcha: only 'a' is a pointer, 'b' is a plain ikeStruct!
    ikeStruct *a, *b;  // both a and b are pointers
    ```
